# Automated Insight Generation

This project analyzes healthcare performance data across different districts to identify trends, outliers, correlations, and generate insights.

- **`script.ipynb`**: Performs data loading and validation, trend detection, IQR-based outlier detection, Pearson correlation analysis, and automated insight generation.
- **`app.py`**: Provides a Streamlit interface to view analysis results, charts, insights, and apply filters.

## Run the Application

```bash
pip install -r requirements.txt
streamlit run app.py
```
